Detailed Description

Task 5 - Evaluate a propositional-logic formula bottom-up on its parse tree and produce the complete truth table.

Input : a fully parenthesized INFIX formula (~ negation, + OR, * AND, > implication) Output: the truth table of the formula, plus whether it is a tautology, a contradiction, or merely satisfiable.

The Node structure and the infix -> parse tree parser are the same as in task1.c, so they are reused here unchanged.

Complexity: for a formula with n nodes and k distinct atoms, the table has 2^k rows and each row is evaluated in O(n) time, so the total time is O(2^k * n). The evaluation uses O(h) call-stack space, where h is the tree height, plus O(k) for the atom table.

◆ evaluate()

int evaluate ( const Node * n,
const AtomTable * t,
const int * val )

Evaluate the formula bottom-up (post-order).

The values of the children are computed first, then the connective at the node combines them: '*' is AND, '+' is OR, '~' is NOT and '>' is implication (computed as NOT a OR b).

Time O(n) per assignment; extra memory O(h) for the call stack.

Parameters
nRoot of the (sub)tree; must not be NULL.
tAtom table giving the position of every atom.
valTruth values (0 or 1); val[i] is the value of atom t->names[i].
Returns
Truth value (0 or 1) of the subtree.
