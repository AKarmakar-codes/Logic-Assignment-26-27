Detailed Description

Task 2 - Convert a prefix propositional-logic formula into a rooted binary parse tree.

The prefix formula is read recursively: a binary connective is followed by its left and right operands, a negation by its single operand, and an atom is a leaf. The resulting tree is verified by printing it back as a fully parenthesized infix formula.

Connective symbols used: ~ for negation, + for OR, * for AND and

for implication.

Input methods supported (as per course guidelines):

  1. Manual prefix/infix formula from stdin (hand testing).
  2. DIMACS CNF benchmark file (.cnf) converted to prefix and parsed into a tree.

Complexity: O(n) time for building, printing and freeing the tree; O(h) extra memory for the recursion, where h is the tree height.

◆ parse_prefix()

Node * parse_prefix ( void )
static

Recursively parse one prefix formula starting at the global pointer.

  • A binary connective is followed by its left and then its right operand.
  • '~' is followed by a single operand, which becomes its left child.
  • Anything else is read as an atom (letters and digits).

The program exits with an error message on an unexpected end of input or an invalid symbol.

Returns
Root of the parse tree for the formula that was read.
