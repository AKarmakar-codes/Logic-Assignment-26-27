Detailed Description

Task 3 - Recursive and iterative in-order, pre-order and post-order traversals of a propositional-logic parse tree.

Input : a fully parenthesized INFIX formula (~ negation, + OR, * AND, > implication) Output: in-order (infix), pre-order (prefix) and post-order (postfix) of the parse tree, each produced recursively AND iteratively.

The tree is built with the same parser used in task1.c, so the Node structure is identical to the one used in task1.c / task2.c.

Complexity: every traversal visits each node once, so all six run in O(n) time. The recursive versions use O(h) call-stack space, where h is the tree height. The iterative versions use an explicit stack of O(h) frames, except the two-stack post-order, which needs O(n) space.

◆ inorder_iter()

void inorder_iter ( const Node * root)

In-order (infix, brackets omitted) traversal, iterative.

Each stack frame remembers how far we got with that node:

  • state 0 : just arrived -> go to the left child
  • state 1 : left is done -> print the label, go to the right child
  • state 2 : right is done -> pop

Produces the same output as inorder_rec().

Parameters
rootRoot of the tree to traverse; may be NULL.
