Detailed Description

Task 4 - Height of a propositional-logic parse tree, computed recursively and iteratively.

Height convention: number of EDGES on the longest root-to-leaf path (a single atom has height 0). The number of levels = height + 1.

Input : a fully parenthesized INFIX formula (~ negation, + OR, * AND, > implication) Output: the height of its parse tree, computed by both methods.

◆ height_iter()

int height_iter ( const Node * root)

Compute the height of a parse tree, iteratively (level-order / BFS).

Processes the tree one level at a time using a queue; the number of levels visited minus one is the height. The queue is a heap array that doubles in size when full.

Time O(n); extra memory O(w), where w is the maximum width of the tree.

Parameters
rootRoot of the tree; may be NULL.
Returns
Height of the tree in edges, or -1 for an empty tree.

◆ height_rec()

int height_rec ( const Node * n)

Compute the height of a parse tree, recursively.

Uses height(NULL) = -1, height(leaf) = 0 and height(n) = 1 + max(height(left), height(right)).

Time O(n); extra memory O(h) for the call stack, where h is the height.

Parameters
nRoot of the (sub)tree; may be NULL.
Returns
Height of the tree in edges, or -1 for an empty tree.
