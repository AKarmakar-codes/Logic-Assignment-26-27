Detailed Description

Task 1 - Convert a fully parenthesized infix propositional-logic formula into a prefix formula using an operator stack.

Implements Task 1 of Assignment 1. Connective symbols used: ~ for negation, + for OR, * for AND and

for implication.

Reference for infix-to-prefix using operator stack: http://scanftree.com/Data_Structure/infix-to-prefix

Input methods supported (as per course guidelines):

  1. Manual infix formula entered from stdin (hand testing).
  2. DIMACS CNF benchmark file (.cnf) converted into fully parenthesized infix.

Complexity: O(n) time and O(n) auxiliary memory for operator stack conversion.

◆ infix_to_prefix_stack()

void infix_to_prefix_stack ( const char * infix,
char * prefix_out )

Convert an infix formula into prefix notation using an operator stack.

Follows the standard ScanfTree infix-to-prefix algorithm:

  1. Tokenize formula and scan tokens from right to left.
  2. Operands (atoms) are appended directly to the output.
  3. Closing parentheses ')' are pushed to the operator stack.
  4. Opening parentheses '(' trigger popping operators until matching ')' is found.
  5. Operators are pushed according to precedence.
  6. Reversing the collected output tokens produces the final prefix expression.
Parameters
infixNull-terminated, fully parenthesized infix formula.
prefix_outOutput buffer receiving space-separated prefix tokens.

int read_input_cnf ( const char * filename,
char * buffer,
size_t max_len )

Input Method 2: Read a DIMACS CNF file and convert it into fully parenthesized infix notation.

In accordance with DIMACS CNF specifications:

  • Lines starting with 'c' are comments.
  • The problem line starts with 'p cnf <variables> <clauses>'.
  • Literals within a clause are combined with OR ('+').
  • Clauses are combined with AND ('*').
  • Negative numbers represent negated literals (~xK).
Parameters
filenameFile path to the DIMACS CNF benchmark file.
bufferOutput buffer to receive the fully parenthesized infix formula.
max_lenMaximum capacity of the output buffer.
Returns
0 on success, -1 if the file could not be read or opened.
