Detailed Description

Task 1 - Convert a fully parenthesized infix propositional-logic formula into a prefix formula.

The infix formula is first parsed into a binary parse tree. A pre-order traversal (node, left subtree, right subtree) of that tree then yields the prefix expression.

Connective symbols used: ~ for negation, + for OR, * for AND and

for implication.

Input : a well-formed, fully parenthesized infix formula, read from stdin. Output: the equivalent prefix formula, with tokens separated by spaces.

Complexity: parsing, traversal and clean-up are each O(n) in the number of characters/nodes; the output string uses O(n) memory.

Node * parse_formula ( void )

Recursively parse a fully parenthesized infix formula.

Reads from the global input pointer p. The grammar is:

formula := atom | '~' formula | '(' formula [op formula] ')'
op := '+' | '*' | '>'
